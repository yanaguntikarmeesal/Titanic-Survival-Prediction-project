### 🚢 Titanic Survival Prediction - Project Summary

**Titanic Survival Prediction** is an interactive Machine Learning web application that predicts whether a Titanic passenger would have survived.

Built using **Python, Logistic Regression, NumPy, Pandas, and Streamlit**, the app takes passenger details like Class, Sex, Age, SibSp, Parch, Fare, and Embarked port, encodes them numerically, and passes them to a trained Logistic Regression model to predict survival.

**Live App:** https://titanic-survival-prediction-project-btamxmxaje58znpqgmwnmf.streamlit.app/

**Key Features:**
*   Binary Classification model (0 = Not Survived, 1 = Survived)
*   Interactive Streamlit UI for user input
*   Real-time prediction using Pickle-loaded model (`mode_titanic.pkl`)
*   Input order: `[Pclass, Sex, Age, SibSp, Parch, Fare, Embarked]`

**Workflow:** Titanic Dataset -> Data Cleaning & Encoding -> Feature Selection -> Train/Test Split -> Logistic Regression Training -> Save Model (.pkl) -> Streamlit App -> User Input -> Prediction

**Tech Stack:** Python, Scikit-Learn (Logistic Regression), Pandas, NumPy, Streamlit, Pickle, GitHub, Streamlit Cloud
